# Радар новичков

Тестовое задание, слово «НОВИЧОК». Одна страница для линейного руководителя и HR:
с кем из новичков на испытательном сроке нужно поговорить сегодня и о чём.

## Запуск

Откройте `index.html` в браузере. Сервер, сборка и зависимости не нужны.
Чтобы получить публичную ссылку, положите `index.html` в репозиторий и включите GitHub Pages
(Settings → Pages → ветка `main`, папка `/`).

## Как устроено

- `index.html` — всё приложение. Блок `<script id="core">` содержит чистую логику без DOM:
  демо-данные, шаги адаптации, правила статусов, сортировку, статистику, текст задачи.
  Второй блок `<script>` рисует интерфейс и хранит отметки в `localStorage`.
- Данные придуманы и собираются генератором с фиксированным зерном: 27 человек, 6 подразделений.
  Имена составлены случайно из списков, реальных людей нет.
- Шаги со сроками в днях от выхода: общие (1, 3, 14, 30, 60, 80) и свои для склада,
  магазинов, отдела продаж и офиса. Меняются в массивах `COMMON` и `BY_DEPT`.

## Правила

- Шаг сорван, если срок прошёл, а отметки нет.
- Из нескольких пропущенных подряд разговоров в список попадает только последний.
- Порядок списка: сигнал об уходе, затем больше сорванных шагов, затем кто работает меньше.
- Учитывается итог только последнего разговора. Проблему или сигнал об уходе закрывает кнопка в карточке.
- Руководитель выбирает своё подразделение, выбор запоминается. Любую отметку можно отменить.
